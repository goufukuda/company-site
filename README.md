# スカイライン・テクノロジーズ株式会社 コーポレートサイト

ソフトウェア開発会社「スカイライン・テクノロジーズ株式会社（Skyline Technologies）」のコーポレートサイトです。

## 概要

HTML・CSS・JavaScript を `index.html` 1ファイルにまとめた静的サイトです。外部ライブラリやビルドツールは使用していません。

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピー「テクノロジーで、ビジネスの空を拓く。」 |
| 私たちについて | 会社のミッション・考え方 |
| 事業内容 | Webアプリケーション開発 / モバイルアプリ開発 / クラウド・インフラ構築 / AI・データ活用支援 |
| 数字で見るスカイライン | 実績を数字で紹介 |
| 開発実績 | 配送管理プラットフォーム、オンライン診療予約アプリ、スマート農業データ分析基盤 など |
| 開発の流れ | ヒアリング → ご提案・お見積り → 設計・デザイン → 開発・テスト → リリース・運用 |
| 会社概要 / お知らせ | 会社情報と最新ニュース |
| お問い合わせ | 入力チェック付きのお問い合わせフォーム |

> **注意:** お問い合わせフォームはデモ実装です。入力チェックは行いますが、実際にはどこにも送信されません。

## ブラウザで開く手順

サーバーの起動やインストールは不要です。

### 方法1: ファイルを直接開く

1. Finder（Windows ではエクスプローラー）でこのフォルダを開きます。
2. `index.html` をダブルクリックします。
   - 既定のブラウザ以外で開く場合は、`index.html` を右クリックして「このアプリケーションで開く」（Windows では「プログラムから開く」）からブラウザを選びます。
   - ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

### 方法2: ターミナルから開く

macOS:

```bash
open index.html
```

Windows（PowerShell）:

```powershell
start index.html
```

Linux:

```bash
xdg-open index.html
```
